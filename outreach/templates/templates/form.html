Syntax

{{ '{{first_name}}' }} — merge field. If it's empty for a contact, that contact's sequence pauses instead of sending "Hi ,".

{{ '{{first_name|there}}' }} — merge field with a fallback.

{{ '{{pain_point}}' }} — any custom column from your CSV import.

[[Hi|Hey|Hello]] — spintax: one option is picked per contact, so emails aren't identical.

Deliverability tips

  • Keep first-touch emails under ~120 words, plain text, at most one link.
  • Personalise the first line; ask one low-friction question.
  • Send follow-ups as replies in the same thread (step setting).
  • Warm new mailboxes and keep daily volume modest (Settings → daily limit).
